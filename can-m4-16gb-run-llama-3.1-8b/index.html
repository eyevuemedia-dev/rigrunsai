FAQ

How was this fit calculated?

Weights 4.58 GiB, KV cache 1.00 GiB at 8,192 tokens, engine overhead 0.50 GiB, then 5% headroom, for 6.39 GiB. Fast memory available is 12.0 GiB.

What if I change the quant or the context?

This page is Q4_K_M at 8,192 tokens. A smaller quant or a shorter context lowers the total. The homepage calculator changes both without a new page.

Can I trust the tokens per second?

The range 11–20 tok/s is a bandwidth roofline, 55% to 80% efficient. This dense model reads the whole weight file each token. Measure your own box before you buy around it.

What do I type?

Is Apple M4, 16 GB assumed to have extra RAM?

No separate RAM pool. The chip's unified memory is the whole budget, minus the OS reserve described on the methodology page.
