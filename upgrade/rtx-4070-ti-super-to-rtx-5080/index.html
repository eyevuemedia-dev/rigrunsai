FAQ

What counts as an upgrade here?

A model newly reaching Fits, or a higher tokens-per-second range when VRAM does not change. Gaming FPS is a different question.

Are the two cards measured the same way?

Both use 8,192 tokens, the recommended quant, and 32 GB of assumed system RAM. Bandwidth is 672 GB/s versus 960 GB/s.

Should I buy this for local AI?

Buy VRAM first when a model you want is in Offload or No. Buy bandwidth when the model already fits and you want more tokens per second.
