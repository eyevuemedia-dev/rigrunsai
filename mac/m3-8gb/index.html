FAQ

What does the verdict for Apple M3, 8 GB mean?

Memory is the GGUF file, plus KV cache at 8,192 tokens, plus a 0.5 GiB engine allowance, then 5% headroom. Fits means that total is at most 85% of fast memory. Tight means it still fits. Offload means it needs system RAM. No means it does not fit in VRAM plus system RAM after an 8 GB Windows reserve. The formula is on the methodology page.

What memory did you count as usable?

Fast memory is the 8 GB pool minus a 3.0 GB OS reserve (25% of unified memory, at least 3 GB and at most 12 GB).

Why is speed a range?

Decode speed is memory bandwidth divided by the bytes read per token. The high end is 80% of that roofline on the weights alone. The low end is 55% once the KV cache at the working context is included. It is not a benchmark.

How should I run Gemma 4 E2B?

The table uses Q4_K_M. Ollama's matching command is `ollama run gemma4:e2b`. That blob is the library default and can differ from the cited GGUF by a few hundred MB.
