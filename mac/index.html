FAQ

How much unified memory do I need on a Mac for local LLMs?

macOS keeps part of unified memory for itself, and our Mac verdicts subtract an OS reserve. At 8K context a 16 GB Mac fits 18 of 33 (largest Qwen2.5 14B Instruct), a 32 GB Mac fits 30 of 33 (largest Qwen3.6 35B-A3B), and a 64 GB Mac fits 32 of 33 (largest Qwen2.5 72B Instruct).

Why does memory bandwidth matter so much on a Mac?

Generation speed is roughly bandwidth divided by the bytes read per token. A Max chip has several times the bandwidth of a base chip with the same memory, so it runs the same model several times faster.

Should I buy a Mac or a GPU for local AI?

A Mac with lots of unified memory holds bigger models than any single consumer GPU, quietly and at low power. A discrete GPU is faster per dollar on models that fit in its VRAM and much faster at prompt processing. Compare the Mac table here with the GPU hub.
