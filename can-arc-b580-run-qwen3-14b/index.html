FAQ

How was this fit calculated?

Weights 8.38 GiB, KV cache 1.25 GiB at 8,192 tokens, engine overhead 0.50 GiB, then 5% headroom, for 10.6 GiB. Fast memory available is 12.0 GiB.

What if I change the quant or the context?

This page is Q4_K_M at 8,192 tokens. A smaller quant or a shorter context lowers the total. The homepage calculator changes both without a new page.

Can I trust the tokens per second?

The range 24–41 tok/s is a bandwidth roofline, 55% to 80% efficient. This dense model reads the whole weight file each token. Measure your own box before you buy around it.

Is Intel Arc B580 assumed to have extra RAM?

Yes. Discrete GPU pages assume 32 GB of system RAM. Offload uses whatever remains after 8 GB for Windows, and it is limited by the slower of DDR5-5600 and the PCIe link.
