Amazon Associates

As an Amazon Associate we earn from qualifying purchases. RigRunsAI links to Amazon for the GPUs and computers it covers.

Model pages link to Hugging Face files so you can see the byte size. Hardware pages link to the spec source for VRAM and bandwidth. Those are citations, and RigRunsAI is not paid when you open them.

The green "Check price on Amazon" buttons on hardware, upgrade and answer pages are Amazon affiliate links, marked rel="sponsored". If you buy through one, we may earn a commission at no extra cost to you. Affiliate links never change a fit verdict.

FAQ

Are GPU names affiliate links?

No. A GPU name links to its RigRunsAI page. Only the labeled Amazon buttons are affiliate links. Vendor spec links go to the vendor or the spec database cited for that number.

Which programs do you use?

Amazon Associates. Each affiliate link is labeled where it appears, and this page will name any new program.

Does sponsorship count?

A sponsor slot is advertising, described on the sponsor page. It is not an affiliate link, and it does not change a fit verdict.
