FAQ

What does new mean?

The Hugging Face repo creation date of the official model, not a review date. GGUF repos are often created later and are not the sort key.

How fast can a model show up?

A model is added when its config.json and a single-file GGUF size can both be cited. A name without those files waits.

Why is the 5070 Ti the reference?

It is a current 16 GB gaming card, which is the common 'can I run the new one' question. The model page has the rest of the machines.
