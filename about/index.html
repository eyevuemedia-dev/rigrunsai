About RigRunsAI

RigRunsAI answers one question: can the gaming PC, handheld or Mac you already own run a given open AI model locally, and how well? Each answer is a fits, tight, offload or no verdict for a specific model and a specific GPU or Mac configuration, with the sources linked on the page.

How the verdicts are made

  • Weights are the byte size of the actual GGUF file on Hugging Face, not parameters times a guessed bits-per-weight.
  • KV cache is calculated at 8,192 tokens from the model's own config.json (layers, KV heads, head dimension).
  • Overhead is a flat 0.5 GiB engine allowance plus 5% headroom.
  • Hardware VRAM, unified memory and memory bandwidth come from the vendor spec page or the spec database cited for that number. Speed guidance follows memory bandwidth and is labeled as an estimate, not a benchmark.
  • Specs that could not be read from a config, a GGUF header or a vendor page are left out rather than guessed.

The full formula and a worked example are on the methodology page, and the underlying data is published as models.json and hardware.json under CC-BY 4.0. New pages are listed on what's new.

Who runs RigRunsAI

RigRunsAI is published by EYEVUE Ventures, an independent publisher. It is not affiliated with NVIDIA, AMD, Intel, Apple, Hugging Face or any model developer, and none of them review pages before they are published.

How the site makes money

The labeled "Check price on Amazon" buttons are affiliate links. As an Amazon Associate we earn from qualifying purchases. Any other program will be named on the affiliate disclosure page. Affiliate links and any labeled sponsor placement never change a fit verdict.

Fine print

A verdict is a planning estimate for a published file at a stated context length. Real results vary with drivers, the inference engine, other apps using VRAM, longer context and quantization choices. Check the model's license before using it.
