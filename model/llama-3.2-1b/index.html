FAQ

Why Q4_K_M?

Q4_K_M is the quant this page recommends. The file is Llama-3.2-1B-Instruct-Q4_K_M.gguf at 0.75 GiB. Other single-file quants are in the table when a real size was available.

Where do the architecture numbers come from?

GGUF metadata: llama.block_count, embedding_length, head counts, key_length, context_length. Parameter count is gguf.total from the Hugging Face model API. Source: https://huggingface.co/bartowski/Llama-3.2-1B-Instruct-GGUF/blob/main/Llama-3.2-1B-Instruct-Q4_K_M.gguf

Does this include a long context?

The fit uses 8,192 tokens, or less when that is all the fast memory can hold. The model file allows up to 131,072 tokens, and KV cache grows as you use more of that.

What is the Ollama command?

ollama run llama3.2:1b. The library tag is Q4-class or the vendor quant. Compare it with the GGUF linked on this page before you treat the sizes as identical.
