FAQ

Which local model should I start with?

Pick the largest model that fits your memory with room for context. On an 8 GB card that is usually an 8B model such as Qwen3 8B or Llama 3.1 8B; on 16 GB, gpt-oss-20b or a 14B model; on 24 GB, a 32B model such as Qwen3 32B. The best-model-for pages list our picks per VRAM tier.

What does Q4_K_M mean?

It is a 4-bit GGUF quantization from llama.cpp that keeps most of the model's quality at roughly a quarter of the 16-bit size. We list the recommended quant's real file size from Hugging Face, which is what has to fit in memory along with the KV cache.

Why do MoE models run faster than their size suggests?

Mixture-of-experts models such as Qwen3 30B-A3B and gpt-oss-20b only read a few experts per token, so generation reads far fewer bytes than the file size. The whole file still has to fit in memory, or the inactive experts have to sit in system RAM.

How is 'fits on N GPUs' counted?

For each of the 34 PC GPUs we track, the model counts if it reaches Fits or Tight at its recommended quant with 8,192 tokens of context and our 0.5 GiB engine allowance and 5% headroom. Longer context needs more memory.
