FAQ

Why Q4_K_M?

Q4_K_M is the quant this page recommends. The file is Llama-3.2-3B-Instruct-Q4_K_M.gguf at 1.88 GiB. Other single-file quants are in the table when a real size was available.

Where do the architecture numbers come from?

GGUF metadata on the Q4_K_M file. Meta's config.json is access-gated. Source: https://huggingface.co/bartowski/Llama-3.2-3B-Instruct-GGUF/blob/main/Llama-3.2-3B-Instruct-Q4_K_M.gguf

Does this include a long context?

The fit uses 8,192 tokens, or less when that is all the fast memory can hold. The model file allows up to 131,072 tokens, and KV cache grows as you use more of that.

What is the Ollama command?

ollama run llama3.2:3b. The library tag is Q4-class or the vendor quant. Compare it with the GGUF linked on this page before you treat the sizes as identical.
