Gemma 4 model sized for laptops and handhelds. 35 sliding layers (window 512) and 7 full layers. Sliding layers use head_dim and num_key_value_heads. Full layers use global_head_dim. When num_global_key_value_heads is null, full layers keep num_key_value_heads.

FAQ

Why Q4_K_M?

Q4_K_M is the quant this page recommends. The file is gemma-4-E4B-it-Q4_K_M.gguf at 4.64 GiB. Other single-file quants are in the table when a real size was available.

Where do the architecture numbers come from?

Official text_config: layer_types, sliding_window, head_dim, global_head_dim, num_key_value_heads, num_global_key_value_heads. Source: https://huggingface.co/google/gemma-4-E4B-it/raw/main/config.json

Does this include a long context?

The fit uses 8,192 tokens, or less when that is all the fast memory can hold. The model file allows up to 131,072 tokens, and KV cache grows as you use more of that.

What is the Ollama command?

ollama run gemma4:e4b. The library tag is Q4-class or the vendor quant. Compare it with the GGUF linked on this page before you treat the sizes as identical.

Does this include image input?

No. Weight memory is the cited language-model GGUF. A separate vision projector, when one exists, needs more memory.
