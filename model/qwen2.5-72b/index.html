FAQ

Why Q4_K_M?

Q4_K_M is the quant this page recommends. The file is Qwen2.5-72B-Instruct-Q4_K_M.gguf at 44.2 GiB. Other single-file quants are in the table when a real size was available.

Where do the architecture numbers come from?

Official config.json. head_dim = hidden_size / num_attention_heads. Source: https://huggingface.co/Qwen/Qwen2.5-72B-Instruct/raw/main/config.json

Does this include a long context?

The fit uses 8,192 tokens, or less when that is all the fast memory can hold. The model file allows up to 32,768 tokens, and KV cache grows as you use more of that.

What is the Ollama command?

ollama run qwen2.5:72b. The library tag is Q4-class or the vendor quant. Compare it with the GGUF linked on this page before you treat the sizes as identical.
