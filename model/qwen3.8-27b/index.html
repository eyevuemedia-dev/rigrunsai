FAQ

Why UD-Q4_K_M?

UD-Q4_K_M is the quant this page recommends. The file is Qwen3.8-27B-UD-Q4_K_M.gguf at 15.3 GiB. Other single-file quants are in the table when a real size was available.

Where do the architecture numbers come from?

text_config layer_types and linear attention dims. No verified Ollama tag for this exact revision. Source: https://huggingface.co/Qwen/Qwen3.8-27B/raw/main/config.json

Does this include a long context?

The fit uses 8,192 tokens, or less when that is all the fast memory can hold. The model file allows up to 262,144 tokens, and KV cache grows as you use more of that.

Why is there no Ollama command?

No Ollama library tag was verified for this exact model revision. A nearby tag can be a different checkpoint, so it is left off.

Does this include image input?

No. Weight memory is the cited language-model GGUF. A separate vision projector, when one exists, needs more memory.
